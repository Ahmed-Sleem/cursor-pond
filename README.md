# Cursor Pond

Three procedurally animated koi follow your cursor in a transparent, responsive canvas.

**Live:** https://ahmed-sleem.github.io/cursor-pond/

Adapted from [Nagomi](https://github.com/msk1039/nagomi) by Mayank Kadam under the PolyForm Noncommercial License 1.0.0. This extraction contains only the three large koi, their schooling and cursor-following behavior, and fish rendering—no pond, water, plants, weather, audio, controls, or small fish.

```bash
npm install
npm run dev
npm run verify
```
